# Задача 1 — готово

**Что построено.** Приложение TBD теперь существует: это один файл `index.html`, который открывается
двойным щелчком (без интернета-сервера, без сборки, без установки). Внутри него — и внешний вид,
и вся логика, и хранение данных. Данные пишутся только в этот браузер: ничего никуда не отправляется.

## Что уже работает

- **Шапка**, которая всегда видна при прокрутке: название слева; справа — «плюс», настройки и справка.
  Линия под шапкой заканчивается ровно там же, где начинаются и заканчиваются карточки списков.
- **Списки и пункты**: создание («плюс» в шапке — список, «плюс» справа у открытого списка — пункт),
  ввод названия сразу в карточке с автопереходом курсора (Enter — сохранить, Esc — отменить,
  пустой новый объект исчезает), открытие/закрытие списков кликом по названию, отметка выполнения.
  Сделанное становится серым (без зачёркивания); если выполнены все пункты — сереет и название списка.
- **Панель справа** с двумя кнопками: раскрыть все списки / свернуть все списки. Кнопка гаснет,
  когда действие уже бессмысленно (всё раскрыто / всё свёрнуто).
- **Настройки** (шестерёнка, меню строго под кнопкой, правый край по кнопке): тема, язык
  (11 языков + «авто»), куда добавлять новый список (выше/ниже всех), куда добавлять пункт
  (выше/ниже всех), размер страницы (Все, 10, 20, 30, 50, 80, 130, 210) и кнопка «Архив».
  Всё сохраняется и применяется сразу, в том числе если открыть приложение вторым окном.
- **Темы**: системная (следует за настройкой устройства, переключается на лету), тёмная, светлая.
  Страница не вспыхивает белым при открытии в тёмном режиме.
- **Приспособление под экран**: узкие телефоны и широкие мониторы, большие кнопки нажатия,
  безопасные зоны вокруг «чёлки» и жеста домой, длинный текст обрезается многоточием в одну строку.
- **Справка** по кнопке «?» — короткая инструкция.

## Надёжность данных

- Данные переживают перезагрузку и закрытие браузера.
- Если память браузера недоступна (приватный режим), приложение не ломается: работает до закрытия вкладки.
- Сломанный или чужой файл данных не роняет приложение: оно отбрасывает непонятное и стартует чисто.
  Записи, сделанные более новой версией приложения, никогда не перезаписываются старой.
- Данные из памяти проверяются и «починяются» перед использованием: чужие поля убираются,
  повторяющиеся идентификаторы получают новые, пустые и кривые записи отбрасываются.
- Два открытых окна синхронизируются.
- **Защита от подмены текста**: в название списка или пункта можно вписать HTML-код или скрипт —
  он будет показан как обычный текст и ничего не выполнит (проверено).

## Как проверялось

Открыто в реальном браузере (десктоп 1280px и телефон 390px, светлая и тёмная темы):
создание и правка, отметки, сворачивание/раскрытие, все настройки и их сохранение, перезагрузка,
битый JSON, строки с попыткой взлома, недоступность одного и обоих серверов иконок, работа с клавиатуры,
чтение данных, записанных более новой версией приложения (они остаются целыми).
Ошибок в консоли нет. Проверки качества кода (`npm run lint:js`, `npm run lint:css`, `npm run syntax`) проходят чисто.

## Что специально осталось на задачи 2–5

- Тексты интерфейса пока на английском: свой переводческий движок (11 языков, автоопределение) — задача 2.
  Выбор языка уже сохраняется и применяется к странице.
- Размер страницы сохраняется, но деление на страницы — задача 2.
- «Архив» пока сообщает, что раздела ещё нет: сам архив — задача 5. Кнопка рабочая, не пустая.
- Полные тексты во всплывающем окне, прилипание заголовка списка, жесты, перетаскивание,
  пакетный режим, полноценная справка — задачи 2–5.

## Что стоит знать

- Иконки приходят из внешнего бесплатного шрифта: нужен интернет при открытии. Если первый сервер
  недоступен, подключается второй; если недоступны оба — вместо иконок кнопки остаются подписанными
  для читалок с экрана и подсказок, приложением можно пользоваться. Локальной копии иконок в файле нет —
  так требует правило «всё в одном файле, иконки только внешние».
- Кнопка «свернуть все» выглядит как две стрелки внутрь полосы: это стандартная пара иконок
  «развернуть/свернуть», но на маленьком размере она похожа на крестик. При финальной полировке
  стоит посмотреть на неё свежим глазом.
- Итоговая проверка «много списков и очень длинные списки» — на задаче 2, где появится пагинация;
  сейчас свёрнутые списки свои пункты вообще не отрисовывают, поэтому тормозов нет.
- Нажатие на кнопку в тот момент, когда открыто поле ввода, может «потеряться»: сохранение текста
  перерисовывает список, и клик приходит уже на другой элемент. Так же обновление из второго окна
  может стереть то, что печатаешь в первом, а фокус после обновления возвращается в первую кнопку
  элемента, а не в ту, на которой был. Лечится общим механизмом точечного обновления списка — задача 2.
- Если память браузера переполнится и перестанет сохранять, пользователь об этом не узнает
  (сейчас это видно только служебному журналу): строка предупреждения появится вместе с переводами
  в задаче 2.
