# Задача 1 — исправления после проверки качества

**Коротко.** Все 8 замечаний исправлены. Пустых «призраков» не остаётся; если сохранение невозможно — на экране понятная строка, а не молчаливая потеря. Проверено в реальном браузере.

| № | Замечание | Что сделано |
|---|-----------|-------------|
| 1 | **Пустые списки и пункты сохранялись сами** (существенное) | Новый объект записывается только с появлением текста. Любое расставание с пустой карточкой — обновление страницы, закрытие вкладки, второе «+» — не оставляет следа. Не сохранённый Enter'ом текст при обновлении уходит без следа: карточка «Untitled» не появляется ни в одном из 4 сценариев замечания. |
| 2 | **Правки поверх «новой версии» данных не сохранялись молча** | Над списками строка: данные сохранены более новой версией приложения, изменения не сохранятся. Ничего не портится. |
| 3 | **Недоступная память браузера — без предупреждения** | Та же строка: «не могу сохранять; всё пропадёт при закрытии вкладки». Появляется сразу (приватный режим) или в момент первой неудачной записи (кончилось место), озвучивается программам чтения с экрана. Задача 2 переведёт её на 11 языков. |
| 4a | **После Enter фокус уходил в квадратик отметки, быстрое добавление неудобно** | Enter сохраняет пункт и сразу открывает поле следующего: список набирается подряд. Esc заканчивает набор — пустая карточка исчезает. |
| 4b | **Нажатие «+» во время ввода терялось** | Сохранение текста дожидается уже начатый клик: одно «+» = сохранил и открыл новое поле. Галочка и сворачивание списка, нажатые во время ввода, тоже больше не теряются. |
| 5 | **Кнопка «свернуть все» выглядела как крестик** | Новая пара иконок: две стрелки расходятся от полосы = раскрыть все, две сходятся к полосе = свернуть все. |
| 6 | **Меню настроек не удерживало фокус** | Открыли меню — фокус в его первом пункте; Tab ходит по кругу внутри меню, не утекает в шапку; «сбежал» (клик по шестерёнке или пустому месту) — следующая Tab вернёт в меню. Esc и клик мимо закрывают как раньше, фокус возвращается на шестерёнку. |
| 7 | **Панель кнопок ломала разметку доступности** | Кнопки размечены корректно: проверка доступности (axe) — 0 ошибок и 0 предупреждений (было 2+1). Программа чтения с экрана объявляет их группой. |
| 8 | **Кнопка «Архив» обещала архив «следующим шагом»** | Честно: «в более поздней версии» (это задача 5). |

**Как проверялось.** Реальный браузер: 4 сценария замечания №1; печать 4 пунктов Enter'ами подряд и остановка по Esc; «+», галочка, сворачивание и шестерёнка прямо во время ввода; позиции «над/под всеми»; обновление страницы посреди ввода; Tab/Shift+Tab/Esc в меню; два окна — синхронизация на лету; «данные новой версии» — видны, целы, предупреждение на месте; заблокированная и переполненная память — работает и предупреждает; попытка взлома через название — по-прежнему просто текст; автотест доступности — 0/0; журнал браузера без ошибок; все проверки качества кода чисто. Внешний вид сверен скриншотами: компьютер (светлая/тёмная темы) и телефон 390px.

**Что осталось знать.** Не подтверждённый Enter'ом текст не переживает обновление — так и в похожих приложениях; лишнего при этом не появляется. Плашка-предупреждение, как весь интерфейс задачи 1, по-английски: переводы — задача 2. Границы объёма и финальная полировка — по плану задач 2–5.
